# jake.hwll.me

Personal site for [Jake Howell](https://jake.hwll.me) — software engineer in Sydney.

Built with [Astro](https://astro.build), [Tailwind CSS](https://tailwindcss.com), and [Bun](https://bun.sh). Deployed to GitHub Pages.

Local setup and contribution notes are in [CONTRIBUTING.md](CONTRIBUTING.md).

## Deploy

Pushing to `main` (or the daily cron) builds with Bun and deploys to GitHub Pages via [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

Enable **Pages → GitHub Actions** as the source in repo settings.
